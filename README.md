# 世界の街角ランダムストリートビュー (Random StreetView)

iPhoneに最適化された、1分おきに世界中のランダムな地点のストリートビュー（風景）を映し出すWebアプリケーションです。

---

## 🌟 主な特徴・機能

1. **1分おきの自動切り替えスライドショー**
   - 世界各地（日本、ヨーロッパ、北米、南米、アジア、オセアニア、アフリカなど）の厳選されたストリートビュー・風景が1分ごとに自動でクロスフェード切り替えされます。
   - 画面上部に進行度を示すプログレスバーが表示されます。

2. **余計なボタンのない純粋なストリートビュー表示**
   - 矢印や移動コントロールなどのUIを排し、フォトフレームやデジタルサイネージのような洗練された全画面表示。

3. **画面タップで開くインタラクティブ地図**
   - 画面のどこかをタップすると、下からスライドアップしてその場所の地図（OpenStreetMap）が表示されます。
   - ピン（マーカー）が立っており、周辺の地形や都市との位置関係が一目でわかります。
   - 「Googleマップで開く」ボタンをタップすれば、iPhoneのGoogleマップアプリまたはブラウザで直接詳細を開けます。
   - 地図を開いている間は自動更新タイマーが一時停止し、ゆっくり地図を確認できます。

4. **時計オーバーレイ（小さめ・秒針ありの針時計）**
   - すりガラス調（ガラスモーフィズム）の洗練されたアナログ針時計。
   - 時針・分針に加え、アクセントレッドの秒針がリアルタイムに時を刻みます。

5. **大まかな住所表示**
   - 「番地は含めず、国名から表示」の仕様に基づき、「🇯🇵 日本, 東京都 港区（東京タワー前）」のように見やすく表示されます。

6. **iPhone縦置き・横置き（Portrait / Landscape）完全対応**
   - iPhoneの向きを変えてもレイアウトが自動調整され、セーフエリア（ノッチやダイナミックアイランド、ホームバー）を考慮した配置になります。

7. **Google Maps APIキー対応 & デモモード**
   - **APIキー未設定時**: 組み込みの高品質デモデータ（世界各地の名所・街並み）により、設定不要ですぐに楽しめます。
   - **APIキー設定時**: 右上の設定アイコン（⚙️）からGoogle Maps APIキーを保存すると、Google Street View Static APIから最新の高解像度ストリートビュー画像をリアルタイム取得します。

## 📱 iPhoneでの利用・起動方法

### 同じWi-Fiネットワーク経由でアクセスする場合
Macでローカルサーバーが起動している状態で、同一Wi-Fiに接続したiPhoneのSafariから以下のURLを開きます：

```text
http://192.168.2.27:8080
```
*(※IPアドレスはMacのWi-Fiアドレスです)*

### ホーム画面に追加して全画面Webアプリ（PWA）として使う方法
1. iPhoneのSafariで上記URLを開きます。
2. 画面下部中央の共有ボタン（四角から矢印が上に出ているアイコン）をタップします。
3. メニューから「**ホーム画面に追加**」を選択します。
4. ホーム画面に専用アイコンが配置され、起動するとSafariのアドレスバーやツールバーのない、完全な全画面アプリとして起動します。

## ⚙️ 操作方法

- **画面タップ**: その地点の地図ポップアップを開く
- **右上 ⏸ / ▶ ボタン**: スライドショーの一時停止 / 再開
- **右上 ⏭ ボタン**: すぐに次の地点へスキップ
- **右上 ⚙️ ボタン**: 設定モーダルを開く（Google Maps APIキーの入力、切り替え秒数の変更）
- **地図モーダルの「Googleマップで開く」**: Google Mapsアプリでその地点を表示
