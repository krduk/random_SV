# 世界の街角ランダムストリートビュー (Random StreetView)

iPhoneに最適化された、1分おきに世界中のランダムな地点のストリートビュー（風景）を映し出すWebアプリケーションです。

---

## 🌟 主な特徴・機能

1. **1分おきの自動切り替えスライドショー**
   - 世界各地（日本、ヨーロッパ、北米、南米、アジア、オセアニア、アフリカなど）の厳選されたストリートビュー・風景が1分ごとに自動でクロスフェード切り替えされます。
   - 画面上部に進行度を示すプログレスバーが表示されます。

2. **360°ぐりぐり見回せるパノラマ表示（ジャイロ無効・移動ボタンなし）**
   - 画面を指でドラッグ（スワイプ）して、その場に立ったまま360度上下左右の風景を自由にぐりぐり見回せます。
   - 道路上の矢印や移動コントロール、コンパスなどの余計なボタンは一切非表示。
   - ジャイロ（端末の傾き連動）は無効化し、指先で安定して見回せるように設計。

3. **画面タップで開くインタラクティブ地図**
   - 画面を軽くタップ（または場所カードをタップ）すると、下からスライドアップしてその場所の地図（OpenStreetMap）が表示されます。
   - ぐりぐりスワイプ操作中は地図が開かず、軽く短くタップした時だけ開くスマート判定を搭載。
   - ピン（マーカー）が立っており、周辺の地形や都市との位置関係が一目でわかります。
   - 「Googleマップで開く」ボタンをタップすれば、iPhoneのGoogleマップアプリまたはブラウザで直接詳細を開けます。
   - 地図を開いている間は自動更新タイマーが一時停止し、ゆっくり地図を確認できます。

4. **ドラッグ移動できる半透明ウィジェット（時計 ＆ 住所カード）**
   - 背景の風景がしっかり透けて見えるクリアなすりガラス調（ガラスモーフィズム）。
   - 指で好きな位置へ自由にドラッグ移動可能（位置は自動記憶され、画面回転時も自動追従）。
   - ダブルタップで初期位置へ即座にリセット。
   - 時針・分針に加え、アクセントレッドの秒針がリアルタイムに時を刻みます。

5. **大まかな住所表示**
   - 「番地は含めず、国名から表示」の仕様に基づき、「🇯🇵 日本, 東京都 港区（芝公園・東京タワー前）」のように見やすく表示されます。

6. **iPhone縦置き・横置き（Portrait / Landscape）完全対応**
   - iPhoneの向きを変えてもレイアウトが自動調整され、セーフエリア（ノッチやダイナミックアイランド、ホームバー）を考慮した配置になります。

7. **Google Maps APIキー対応 & デモモード**
   - **APIキー未設定時**: 組み込みの高品質デモデータ（世界各地の名所・街並み）により、設定不要ですぐに楽しめます。
   - **APIキー設定時**: 右上の設定アイコン（⚙️）からGoogle Maps APIキー（「Maps JavaScript API」を有効化したもの）を保存すると、360°ぐりぐり見回せるストリートビューが有効になります。

8. **風景を邪魔しない未読通知ウィジェット（Chatwork ＆ Gmail）**
   - **環境に溶け込むミニマル・グラスモーフィズム**: すりガラス調のスマートなピル型カプセルで、美しい風景パノラマを一切遮りません。
   - **指でドラッグ移動可能**: 時計や場所カードと同様に、画面上の好きな位置へ自由にドラッグして配置できます（位置は自動保存）。
   - **アンビエント・ティッカー（テロップ）**: 未読がある時は、送信元と件名/本文が1行で穏やかにフェード表示されます。未読が0件の時は自動で極小サイズに縮小し、「未読なし ✨」として風景を100%楽しめます。
   - **ワンタップで詳細モーダル展開**: ウィジェットを軽くタップすると、Chatworkの未読メッセージ本文やGmailの送信元・タイトル一覧をすりガラスカードで確認でき、直接サービスを開くこともできます。
   - **デモモード完備**: 初期状態ではリアルなサンプルデータが表示されるため、設定前でもデザインや操作感をすぐに体験できます。
   - **Google Apps Script (GAS) 連携**: 同梱の `NotificationHub.gs` をGASにデプロイしてURLを入力するだけで、CORS制限なくどこからでも安全にリアルタイム通知を取得できます。

## 📬 Chatwork & Gmail 未読通知の連携手順 (GAS)

本アプリには、ChatworkとGmailの未読データをセキュアに取得して配信するGoogle Apps Script (`NotificationHub.gs`) が同梱されています。

### 1. Google Apps Script の作成
1. [Google Drive](https://drive.google.com) を開き、「新規」→「その他」→「Google Apps Script」を選択。
2. プロジェクト名を設定（例: `RandomView-NotificationHub`）。
3. 本アプリフォルダ内の **`NotificationHub.gs`** の中身をすべてコピーしてエディタに貼り付け、保存 (Ctrl+S / Cmd+S)。

### 2. Chatwork API トークンの設定（Chatwork連携時のみ）
1. GASエディタの左側 ⚙️「**プロジェクトの設定**」をクリック。
2. 「**スクリプト プロパティ**」の「スクリプト プロパティを追加」をクリック。
3. 以下を設定して保存:
   - プロパティ: `CHATWORK_API_TOKEN`
   - 値: ご自身のChatwork APIトークン
   *(※Gmailのみ取得する場合はこの手順はスキップして構いません)*

### 3. ウェブアプリとしてデプロイ
1. 右上の「**デプロイ**」→「**新しいデプロイ**」をクリック。
2. 左上の歯車アイコンから「**ウェブアプリ**」を選択。
3. 以下を設定:
   - **次のユーザーとして実行**: `自分`
   - **アクセスできるユーザー**: `全員` *(※アプリからデータ取得するために必要)*
4. 「デプロイ」をクリックし、初回のみGoogleアカウントのアクセス承認を完了します。
5. 発行された「**ウェブアプリのURL**」(`https://script.google.com/macros/s/.../exec`) をコピーします。

### 4. アプリでの設定
1. ランダム風景アプリを開き、右上の **⚙️（設定）** をタップ。
2. 「📬 未読通知 (Chatwork & Gmail)」セクションで:
   - データ連携元: **「🔗 Google Apps Script (GAS) Webアプリ連携」** を選択
   - **GAS Web App URL**: 先ほどコピーしたURLを貼り付け
3. 「**🔗 接続テスト**」をタップして「✅ 接続成功！」と出たら、「**設定を保存する**」をタップして完了です！

## 🌐 Google Apps Script (GAS) Webアプリとして直接使う（Macサーバー不要！）

「ランダム風景アプリ」と「未読通知機能」が丸ごと1つのGoogle Apps Script Webアプリとしてセット化されています。
**Macでローカルサーバーを起動していなくても、どこからでも以下のURLを開くだけで完全動作します！**

### 📱 公開WebアプリURL:
```text
https://script.google.com/macros/s/AKfycby-egT0QCVI6tv4o4XZiq0KvY57erOWlTavyVt8frJIBJr6lvFP9nf03RfmSsXRWS8Z0g/exec
```

* **iPhoneでの利用**: Safariで上記URLを開き、「**ホーム画面に追加**」を選択すれば、Safariのツールバーなしの全画面アプリとして起動します。
* **GAS直接連携**: GAS上で動作しているため、外部fetchやURL設定の手間なく、GmailとChatworkの未読が同一サーバー内で自動的に直接取得されます。

### 🔄 今後の更新方法 (clasp push):
ローカルのソースコード（`app.js`, `style.css`, `index.html` など）を編集した後は、以下のコマンド1つでバンドル＆GAS反映が完了します：

```bash
npm run push     # バンドル生成して clasp push
# または
npm run deploy   # バンドル生成・push・デプロイまで一括実行
```

## 📱 ローカルサーバー経由で利用する場合 (従来方式)

### 同じWi-Fiネットワーク経由でアクセスする場合
Macでローカルサーバーが起動している状態で、同一Wi-Fiに接続したiPhoneのSafariから以下のURLを開きます：

```text
http://192.168.2.27:8080
```
*(※IPアドレスはMacのWi-Fiアドレスです)*

### ホーム画面に追加して全画面Webアプリ（PWA）として使う方法
1. iPhoneのSafariで上記URLを開きます。
2. 画面下部中央の共有ボタン（四角から矢印が上に出ているアイコン）をタップします。
3. メニューから「**ホーム画面に追加**」を選択します。
4. ホーム画面に専用アイコンが配置され、起動するとSafariのアドレスバーやツールバーのない、完全な全画面アプリとして起動します。

## ⚙️ 操作方法

- **画面タップ**: その地点の地図ポップアップを開く
- **通知ウィジェットをタップ**: Chatwork未読 & Gmail未読の詳細モーダルを開く
- **通知ウィジェットをドラッグ**: 画面上の好きな位置へ移動（ダブルタップで初期位置へリセット）
- **右上 ⏸ / ▶ ボタン**: スライドショーの一時停止 / 再開
- **右上 ⏭ ボタン**: すぐに次の地点へスキップ
- **右上 ⭐️ ボタン**: 保存した場所一覧（お気に入り）を開く
- **右上 🔄 ボタン**: アプリを最新状態に再読み込み
- **右上 ⚙️ ボタン**: 設定モーダルを開く（APIキー、探索スタイル、未読通知連携など）
- **地図モーダルの「Googleマップで開く」**: Google Mapsアプリでその地点を表示
